# 109C4 JOB FINDER

موقع ويب عربي/إنجليزي للبحث عن الوظائف من مصادر متعددة، وحفظ سجل البحث والوظائف والسيرة الذاتية محليًا.

## النشر على GitHub Pages مجانًا
1. أنشئ مستودعًا عامًا باسم `109C4-JOB-FINDER`.
2. ارفع جميع ملفات ومجلدات المشروع إلى جذر المستودع.
3. افتح Settings → Pages.
4. في Build and deployment اختر **GitHub Actions**.
5. ادفع الملفات إلى فرع `main` أو شغّل Workflow من Actions.
6. انتظر نجاح `Deploy 109C4 Job Finder to GitHub Pages`.
7. خذ الرابط الحقيقي من Settings → Pages. غالبًا سيكون `https://USERNAME.github.io/109C4-JOB-FINDER/`، ويجب اعتماد الرابط الذي يعرضه GitHub.

## المزايا
- بحث عربي وإنجليزي وقائمة مسميات مصنفة.
- قائمة موسعة لإدخال البيانات والمحاسبة والإدارة والموارد البشرية والتقنية وغيرها.
- فلاتر المنطقة الشرقية ومدن السعودية وكل السعودية والعالم.
- اليوم / آخر 7 أيام / آخر 30 يومًا / كل التواريخ.
- الأحدث والأقدم كخيار لاستعلامات البحث المدعومة؛ كل مصدر يتحكم بترتيبه.
- روابط بحث مباشرة لمنصات توظيف وصفحات شركات.
- سجل بحث ومحفوظات محلية.
- إضافة وظيفة يدويًا برابط الإعلان.
- حفظ السيرة الذاتية في IndexedDB على نفس المتصفح.
- تسجيل دخول ومزامنة اختيارية عبر Firebase.
- فتح مسودة Gmail؛ إرفاق CV يدويًا مطلوب حاليًا.

## حدود مهمة
لا توجد واجهة واحدة تسمح بالبحث الآلي في كل مواقع العالم. الروابط تفتح نتائج البحث في مواقعها، ولا يتم تجاوز تسجيل الدخول أو شروط المواقع. لا ندّعي وجود نتائج مباشرة مجمعة إذا لم يكن هناك API موثوق.
البيانات المحلية لا تنتقل تلقائيًا إلى جهاز آخر. المزامنة تحتاج Firebase. التخزين السحابي للملفات يحتاج Firebase Storage وقواعد مناسبة.

## Firebase (اختياري)
- أنشئ Firebase project وWeb App.
- Authentication: فعّل Email/Password وGoogle.
- أضف `USERNAME.github.io` إلى Authorized domains بعد النشر.
- أنشئ Firestore Database.
- الصق Firebase Web App config في صفحة حسابي.
- استخدم قواعد وصول خاصة بالمستخدم، ولا تفتح القراءة والكتابة للجميع.
